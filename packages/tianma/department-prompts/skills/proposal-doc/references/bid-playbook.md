# 招投标专员手册

投标和写方案是两件事。方案是"我有什么讲给你听"，投标是"你要求什么，我逐条证明我满足"。
**评委只按评分表和符合性审查打分**，所以本文的一切动作都服务于两件事：拿到分、不被废标。

## 一、读标：抽出五张清单

招标文件到手，先别写正文。通读一遍，把它拆成五张可核对的清单——后面所有工作都以这五张清单为准。
文件长（100 页以上）就分两次读：第一遍读"投标人须知 + 评分办法 + 废标条款"，第二遍读技术需求与格式要求。

| 清单 | 从哪抄 | 记什么 |
|---|---|---|
| **资格条件** | 招标公告 + 投标人须知前附表 | 资质等级、注册资本、业绩数量与金额、人员证书、财务指标、是否接受联合体 |
| **评分办法** | 评分表（通常在"评标办法"一章） | 每个得分项的分值、评分细则原文、证明材料的种类与份数 |
| **技术需求** | 技术规格书 / 需求清单 | 逐条编号；标出 **★（不满足即废标）**、**▲（重要，影响打分）**、一般条款 |
| **格式要求** | 投标文件格式章节 | 章节顺序、标题原文、表格样式、是否要求逐页签字盖章、装订与密封方式、份数、正副本、电子件格式 |
| **废标条款** | 投标人须知 + 评标办法里的"否决投标条款" | 逐条抄下来，一条不漏 |

抄的时候保留**原文编号**（如"3.2.1"）。后面偏离表和核对表都用这个编号对回招标文件，甲方一查就能对上。

## 二、拆评分：先算能拿多少分

把评分表抄成一张表，每个得分项配三样东西：

```
得分项 | 分值 | 评分细则（原文） | 我方证据 | 落在第几页 | 把握度（稳/险/无）
```

- **算出理论上限**：技术分 + 商务分 + 价格分，看满分是多少，我方稳拿多少。
- **找丢分点**：把握度"无"的项，要么补材料，要么在正文里用别的方式找补（如用相近业绩顶替要点，但不得改变业绩本身）。
- **决定详略**：分值高的项写满两页也不为过；0 分项一句话带过。这是投标和写方案最大的差别——**篇幅跟着分值走，不跟着逻辑走**。

价格分单独算。若招标文件给了价格分公式（如"基准价/投标价×30"），先把公式抄进核对表，报价时按公式反算最优区间。

## 三、定目录：照抄，不自创

投标文件的章节顺序、标题文字、编号，**一律照招标文件"投标文件格式"章节原文**。招标文件写"（三）商务响应表"，就不要改成"商务条款应答"。

常见骨架（招标文件没规定时才用）：

```
封面 → 目录 → 投标函 → 开标一览表（报价表）→ 法定代表人身份证明 / 授权委托书
→ 资格证明文件（营业执照、资质证书、财务报告、信用证明）
→ 商务响应（商务偏离表 + 商务条款逐条应答）
→ 技术响应（技术偏离表 + 技术方案 + 项目实施计划 + 人员配置）
→ 业绩与案例（合同、验收证明）
→ 售后服务承诺
→ 其他（优惠承诺、廉洁承诺、保证金凭证）
→ 附件
```

三件事容易漏：

1. **投标函与开标一览表的金额必须完全一致**，大写与小写也要一致——不一致按废标处理。
2. **授权委托书**要有法定代表人签字（或签章）与被授权人身份证复印件，日期不能早于招标公告发布日。
3. **目录页码**要与正文一致。本技能的目录是 `PAGEREF` 域，改完重跑一次即可，别手工填。

## 四、逐条响应：偏离表是主战场

技术响应表和商务偏离表统一用四列：

| 条款号 | 招标要求（原文摘录） | 我方响应 | 证明材料 |
|---|---|---|---|
| 3.2.1 ★ | 支持不少于 200 路视频接入 | 完全响应：平台设计容量 512 路，实测 200 路并发 | 技术方案 12 页；第三方检测报告 P7 |

写法约定：

- **响应栏只有三种结论**：`完全响应` / `优于`（优于要写清优在哪，含数字）/ `偏离`（偏离要写清差在哪、补救措施）。不要写"基本满足""原则上响应"这类模糊话，评审直接判不响应。
- **★条款一律"完全响应"**。真的做不到，当场告诉用户，让商务决定是否放弃投标——写"部分响应"等于自己废标。
- **▲条款逐条应答**，能写"优于"就写"优于"并给数字，这是加分项。
- 一般条款可以合并成"其余条款均完全响应"，但**前提是逐条核对过**，漏一条被评委抽查到就是硬伤。
- 证明材料列写"文件名 + 页码"，与后附材料严格对应；页码错位比不写更糟。

## 五、取证据：只用手上有据的

资质、业绩、人员、财务四类，**只从用户给的目录里取**。

- 业绩：合同首页 + 签章页 + 验收证明三件套齐全才算一条；只有合同没验收的，写"在建/在执行"，不写成效数据。
- 人员：证书编号、发证机关、有效期照抄；过期证书不能写"有效"。
- 财务：以审计报告为准，不要用内部报表。
- 信用：信用中国、裁判文书网的查询截图要带查询日期。

取不到的，列进"待补清单"，交接时逐条点名要。**绝不能**用相近项目顶替、用别家业绩充数、用"预计""约"补数字——这类问题一旦被质疑，整个投标作废，还可能进黑名单。

## 六、报价：开标一览表最容易废标

- 金额三处一致：开标一览表、投标函、报价明细表。**大小写一致**，大小写不一致按废标处理。
- 币种、单位（元/万元）、是否含税、税率，逐项对齐招标文件要求。
- 投标有效期：不少于招标文件规定的天数，写在投标函里。
- 优惠条件：招标文件不允许的（如附条件报价、选择性报价）一律不写，写了就是无效报价。
- 分项报价合计必须等于总价；缺项按"未报价"处理，可能被认定为不响应。

## 七、格式与装订：按招标文件，不按习惯

- 份数：正本 1 份、副本 N 份、电子件 1 份（U 盘或指定平台），以招标文件为准。
- 签字盖章：投标函、开标一览表、授权书、偏离表逐页签章的，一页都不能少；骑缝章按招标文件要求。
- 装订：胶装/骑马钉/活页，招标文件指定哪种就用哪种；活页装订很多项目直接废标。
- 密封：封套标注项目名称、包号、投标人名称、"开标时启封"字样，封口加盖骑缝章。
- 电子件：PDF 还是原生格式、是否需要电子签章、U 盘是否要标注，逐条核对。

本技能的 `scripts/docbuild.py` 负责版式与 PDF；**封面、签章页、份数、密封这些"非版式"要求由人按招标文件处理**，脚本不管。

## 八、废标红线清单（30 条，交付前逐条打勾）

**资格类**
1. 营业执照在有效期内、经营范围覆盖标的
2. 资质等级满足要求（含是否接受分公司/联合体）
3. 业绩数量与金额达标，且能提供合同+验收
4. 项目负责人/技术负责人证书有效、社保在本单位
5. 未被列入失信被执行人、重大税收违法名单
6. 投标保证金足额、按时到账、形式符合要求
7. 联合体协议（如接受联合体）已签署并明确分工

**文件类**
8. 投标文件按招标文件规定格式编制，章节顺序一致
9. 投标函已按格式填写并签字盖章
10. 开标一览表金额与投标函、明细表一致，大小写一致
11. 投标有效期不少于规定天数
12. 授权委托书齐全，法定代表人签字/签章、日期正确
13. 法定代表人身份证明与身份证复印件一致
14. 所有要求签章处已签章，无遗漏页
15. 目录页码与正文一致
16. 无涂改；有涂改处已签章确认
17. 报价唯一，无选择性报价或附条件报价
18. 分项报价合计等于总价，无缺项漏项

**技术类**
19. ★条款逐条"完全响应"，无遗漏、无"部分响应"
20. 技术偏离表覆盖全部技术需求条目，编号与招标文件一致
21. 投标产品/方案与招标需求无实质性负偏离
22. 交货期/工期满足要求
23. 质保期与售后响应时间满足要求
24. 项目实施计划与人员配置表齐全

**装订与提交类**
25. 正副本份数正确，封面标注"正本/副本"
26. 装订方式符合要求（活页/胶装）
27. 密封方式正确，封套标注齐全，封口盖章
28. 电子件格式与载体符合要求
29. 在投标截止时间前送达指定地点
30. 投标人名称在全文一致（含封面、投标函、盖章处）

任一条打不了勾，**先停下来问用户**，不要"先交了再说"。

## 九、交付物

投标模式除投标文件本体外，固定再交两份：

1. **应答核对表**：`条款号 | 招标要求 | 响应结论 | 页码`，覆盖全部★▲条款和评分项。评审核对时按这张表翻，一页都不必找。
2. **废标风险清单**：上面 30 条里没打勾的项，逐条写"风险点 + 建议处置 + 责任人"。

两份都用表格给在对话里或单独 DOCX，**不要塞进投标文件正文**——那属于给甲方看的东西，核对表是给自己人看的。

## 十、时间安排（20 天窗口的常见节奏）

```
D1—D2   读标、拆五张清单、算理论得分        ← 决定要不要投
D3      定目录、分工、要材料（资质/业绩/人员）
D4—D8   技术方案与偏离表初稿
D9—D12  商务、资格、业绩材料归集与核对
D13     报价定稿（走内部审批）
D14—D16 合稿、排版、出 PDF
D17     内部评审：废标红线逐条过
D18     修改、签章、装订
D19     密封、送标
D20     开标备用材料（原件、授权人身份证）
```

留出至少 2 天给"签章与装订"——这两步最容易被低估，也最容易出废标。
