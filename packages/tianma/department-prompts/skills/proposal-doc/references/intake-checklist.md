# 三问清单与缺料降级

> 原则：**先问再写，一次问全**。只问这三组；用户答"没有"，直接走降级模式，不问第二轮。

## 一、开工前必须问的三组

| # | 问题 | 为什么问 |
|---|---|---|
| 1 | **项目是什么、给的是什么材料**？需求文字 / 需求文档 / 原型截图 / 现有系统资料，分别是哪几份？ | 决定需求复述与总体方案能写多实；材料越少，后面越可能删章节 |
| 2 | **是否已有工期与报价的确定值**？ | 本技能不写工期与报价；有确定值就交给商务单列，文档里一律不出现 |
| 3 | **是否有资质业绩材料**？ | 本技能不写资质、合同金额、人员证书与财务数据；没有就不用找 |

## 二、答"没有"即降级

用户对上述任一项答"没有"，或明确说"先做，别问了"：

1. **不再问第二轮**，直接进入降级模式。
2. 缺料对应的**章节、表格、数字表述整段删除**，不改成定性描述，不用经验值补。
3. 在交付说明里单列**"因缺料删除的内容"**：删了什么、缺哪项输入；没有删除项写"无"。
4. 优先级：**不编造 ＞ 结构完整 ＞ 篇幅**。

## 三、判定表

| 缺的是什么 | 删什么 | 不删但要改什么 |
|---|---|---|
| 没有规模数据（面积、点位、并发、单量） | 所有带这些数字的句子与表格行 | 总体工作流程仍可画，不带数字 |
| 没有原型图或系统截图 | 第五章整章删除，目录与章号顺延 | —— |
| 没有业务流程细节 | 第四章对应的链路，只保留能确认的链路 | —— |
| 没有技术选型依据 | 第二章"技术选型"小节与选型表 | 设计原则与总体架构照写 |
| 没有附件或交付物 | 第七章只写已确认的交付物；一件都没有就整章删 | —— |

## 四、提问话术

> 开始写实施方案前，确认三件事（有就发我，没有的直接说"没有"，我按缺料处理，不再追问）：
> 1. 这个项目是什么？手上有什么材料——需求文字、需求文档、原型截图，还是现有系统资料？
> 2. 工期和报价有没有已经谈定的数值？（这两项不进实施方案，有的话我另交给商务）
> 3. 资质、业绩材料有没有？（同样不进实施方案）

## 五、用户说"你定"的时候

本技能不接受"你定个数字"：数字只能来自材料或用户确认。

- 用户让"先做"→ 删除对应内容，登记进"因缺料删除的内容"。
- 用户口述的数字 → 写进 `NUMBERS` 台账，出处记"用户确认"。
- 拿不准 → 不问第二轮，按缺料删除；交付说明里点名。
