# content.py 内容块 DSL

`docbuild.py` 只认两个变量：`META`（dict）与 `CONTENT`（list）。除此之外随便你怎么组织（可以拆多个文件 import 进来）。

## META

```python
META = {
    "title": "肉联厂冷链监控与智慧运营平台",   # 封面主标题（二号宋体加粗）
    "subtitle": "技 术 方 案",                  # 副标题（三号楷体）
    "doc_name": "肉联厂冷链监控与智慧运营平台建设方案",  # 页眉 + 默认文件名
    "org": "宜春市天码信息有限公司",             # 编制单位
    "project_no": "TM-HL-2026-011",              # 无则写 "【项目编号】"
    "client": "【委托单位名称】",                # 委托单位
    "toc_break": 20,                             # 目录第二页从第几条开始（0 基）
}
```

- `toc_break`：目录条目满一页是 22 行（含标题占 1 行则 21 条），超出的部分放到第二页并自动加"（续）"。**生成后看目录实际页数再调**：第一页放不下会挤到第二页，且标题重复。
- `org` 与日期都不用传：日期由脚本取系统当天，写成"二〇二六年十一月二日"。

## CONTENT 块类型

| 块 | 写法 | 说明 |
|---|---|---|
| 章 | `("h1", "第一章　项目概述与需求理解")` | 自动另起页、进目录、黑体二号居中。章序号用中文数字，标题与序号间用全角空格 |
| 节 | `("h2", "一、项目背景")` | 黑体三号、左空二字、进目录 |
| 正文 | `("p", "正文……")` | 仿宋三号、首行缩进 2 字符、两端对齐 |
| 带引子的段 | `("lead", "（一）现状。", "……")` | 前段楷体三号、后段仿宋三号，同段起排；**二级标题都用这个** |
| 三级标题段 | `("lead", "1. 建设内容。", "……")` | 三级标题规定用仿宋，所以这里前后段都是仿宋即可（也可以直接用 `p` 把"1. 建设内容。"写在段首） |
| 图 | `("fig", "fig03.png", "图3　模块工作流程图")` | 图宽默认 154mm；要改宽加第 4 项：`("fig", "fig09.png", "图8　原型界面", 150)` |
| 表 | `("tbl", T1)` | T1 为 dict，见下 |
| 分页 | `("pagebreak",)` | 手动分页，慎用（章节已自动分页） |

## 表格 dict

```python
T1 = dict(
    caption="表1　需求要素与响应对照表",       # 表号+全角空格+表名，黑体小四居中，置于表上
    headers=["需求主线", "委托方诉求", "本方案响应", "章节"],  # 黑体五号，灰底，居中
    rows=[
        ["降本", "……", "……", "2.3.1"],
    ],
    widths=[24, 46, 60, 26],   # 单位 mm，**合计必须 = 156**
    aligns=["l", "l", "l", "c"],  # 逐列：l 左 / c 中 / r 右
)
```

- 列宽怎么分：先给每列估一个"最长内容大概多少字"，中文按 3.7mm/字（五号）、数字按 1.9mm/字符算，再加 3mm 内边距；加起来不到 156 就按比例放大。
- **数字列一律右对齐**，文字列左对齐，短枚举（状态、比例）居中。
- 行高按内容自适应，不要手工设；单元格文字会自动换行。
- 首列常放"序号/模块号"，宽度 10~12mm 即可；表头写"序号"两字在 10mm 里会折行，给 11~12mm。

## 图的尺寸经验

| 图型 | 建议宽度 | 高度 |
|---|---|---|
| 横版流程（五段） | 1600 px | ≈560 px（缩到 154mm 后约 54mm 高） |
| 竖版流程（6~8 节点） | 1400~1520 px | ≤1100 px（约 110mm 高，接近一页的 45%） |
| 分层架构 | 1600 px | ≈750 px |
| 甘特图 | 1600 px | ≈600 px |
| 界面原型 | 1240×800 px | 缩到 150mm 宽后约 97mm 高 |

**一页最多放两张原型图**（2×97 + 图题 ≈ 214mm < 225mm）。放流程图时一页一张更稳。

## 成文语言

- 段落一开头就"是什么、为什么"，别用"随着……的发展"凑字数。
- 指标给数字和口径（"不低于 99%""40 秒以内"），不给形容词（"大幅提升"）。
- 客户原话要转写：他说"场地太大看不过来"→ 你写"4 万平方米场地靠人巡，夜间与边角区域存在监控盲区"。
- 拿不准的地方写"待确认"，别用模糊表述糊过去。
