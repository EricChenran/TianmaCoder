# CHANGELOG

## 2.0.0 — 2026-11-06

**收敛为单一文档：实施方案**

- 删除"选模式"表与招投标专员模式（读标、拆评分、偏离表、应答核对表、废标风险清单）；文档类型固定为实施方案，不留开关、不留兼容。
- 固定七章骨架（项目概述与需求理解 / 总体技术方案 / 功能模块技术方案 / 业务流程设计 / 系统演示 / 结论 / 附件与交付清单），不得增删章。
- 新增六类禁令：投标函类、工期与周次、SLA、报价、招标程序、资质业绩；运营建议同样不写。
- 新增缺料降级模式：先三问一次问全，仍缺则删除对应内容并在交付说明列明，优先级"不编造 ＞ 结构完整 ＞ 篇幅"。
- `META` 收敛为 `title` / `subtitle` / `doc_name` / `org`；`project_no` 与 `client` 缺省为空，封面跳过空行、不留【】。
- 新增 `NUMBERS` 数字台账：正文数字必须登记原样字符串与出处，`docbuild.py` 构建前校验，缺项直接报错退出。
- 固化三处实现：目录→正文 `WD_SECTION.CONTINUOUS` 分节且首章自带分页、表头单元格 `keep_with_next`、封面空值跳过与显式置空。
- 删除 `scripts/content_template.py`、`scripts/content_template_bid.py`、`references/bid-playbook.md` 与 `examples/coldchain/`；新增 `scripts/content_template_impl.py`。
- `intake-checklist.md` 改为三问话术与降级判定表。

## 1.0.0 — 2026-11-02

首个版本，由"肉联厂冷链监控与智慧运营平台建设方案"（32 页）的实战过程固化而来。

**新增**

- `SKILL.md`：五步流程（收集资料 → 定结构 → 写 content.py → 画图 → 生成交付）、铁律、版式速查、交付自检。
- `references/intake-checklist.md`：22 条必问清单 + 提问话术 + "用户说你定"时的假设登记规则。
- `references/format-spec.md`：GB/T 9704 参照版式规范全文（页面/字体/行距/序数/表格/页码/封面目录/页眉/印制/检查清单）。
- `references/content-blocks.md`：content.py 的 DSL、表格列宽估算、图型尺寸经验。
- `references/ooxml-recipes.md`：11 条实测坑位（firstLineChars 继承、tblPr 重复元素、pPr 顺序、图片被裁、TOC 域在 LO 下失效、表格孤行、图题串联、奇偶页码、跨页续表、图片细框、像素核对）。
- `scripts/docbuild.py`：content.py → DOCX 主构建器，固化版式；支持 `META` 与 `-o/-n` 参数。
- `scripts/diagrams.py`：通用图元 `vflow / hflow / layers / gantt`。
- `scripts/dkit.py`、`scripts/ui.py`：绘图底层与原型界面组件。
- `scripts/content_template.py`：带注释的内容模板。
- `assets/logo_on_white.png`：白底（深灰字）LOGO，用于封面；`logo_alpha.png` 供深色背景。
- `examples/coldchain/`：完整样例（含 content.py、figures.py、protos.py 与 13 张图），可直接跑通。

**默认口径**

- 编制单位：宜春市天码信息有限公司。
- 编制日期：取运行当天，输出为中文数字格式（如"二〇二六年十一月二日"）。
- 字体：默认用降级名 `仿宋 / 楷体 / 黑体 / 宋体`，避免目标机缺 `_GB2312` 字体导致回退。

**已知限制**

- 表格跨页只做"表头重复"，未自动生成"表N（续）"题注；超过一页的表格建议先压缩到一页。
- 目录不是 Word 原生 TOC 域，而是"条目 + PAGEREF 域"：页码永远正确，但新增章节需重跑脚本，不能靠 Word 的"更新目录"自动加条目。
- LibreOffice 渲染内联图片会加 1px 灰框（Word/WPS 不画），属预览差异。
